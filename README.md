# hxwl-11 眼科验光记录

视力、屈光参数与复查处方对比

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 复查登记功能

- 左右眼分别登记球镜(DS)、柱镜(DC)、轴位(°)，可一键用该患者上次结果预填
- 自动与**同一患者、同一只眼睛**的上次结果比较；球镜或柱镜变化
  **超过 0.25D**（恰好 0.25D 不算）时，在录入表单和记录列表中标红
- 轴位只接受 0–180°，越界（如 181、-1）当场拦住并提示，补正后才能保存
- 保存成功的本次结果即成为下次复查的比较基准；旧记录只追加、不改写，
  每条记录可展开查看该患者全部历史
- 患者（儿童/成人）与镜片类型筛选可叠加使用，四张统计卡随筛选结果实时更新
- 记录持久化在浏览器 localStorage，清空站点数据后回到内置示例数据

## 代码分层

| 模块 | 职责 |
| --- | --- |
| `src/registration.ts` | 登记：表单类型、解析与校验（含轴位 0–180° 拦截），不负责存储 |
| `src/compare.ts` | 比较：纯函数，取同患者上次记录、逐眼计算差值并标记 >0.25D |
| `src/storage.ts` | 保存：记录仓库，只追加写入 localStorage，旧记录保留 |
| `src/stats.ts` | 统计：随当前记录与筛选条件计算看板指标 |
| `src/components/ExamForm.tsx` | 复查登记表单 |
| `src/components/RecordList.tsx` | 记录列表、变化标记与历史展开 |

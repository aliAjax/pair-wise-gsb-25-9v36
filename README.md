# hxwl-11 眼科验光记录

视力、屈光参数与复查处方对比

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 功能

- 领域指标看板（近视进展 / 散光变化 / 复查提醒 / 处方数量，随记录实时计算）
- 患者、人群（儿童/成人）与镜片类型筛选，可叠加
- 复查登记：左右眼分别录入球镜(DS)、柱镜(DC)、轴位(°)
  - 轴位必须为 0–180° 的整数，越界即时标红拦截，补正后才能保存
  - 球镜/柱镜格式校验（如 -2.75，步长 0.25）
- 同眼与该患者上一次结果自动比较：
  - 球镜或柱镜变化严格超过 0.25D 时，列表卡片与具体字段标红（0.25D 本身不标记）
  - 轴位以圆周最短差值展示偏移，不参与 0.25D 判定
- 保存为追加式：旧记录全部保留可查，新记录成为下次比较依据
- 记录持久化在浏览器 localStorage（首次使用载入示例数据）

## 代码结构（登记 / 比较 / 保存分离）

```
src/
  types.ts                     领域类型
  lib/
    registration.ts            登记：常量、格式化、轴位/度数校验
    comparison.ts              比较：找上一次记录、逐参数差值与超阈标记
    storage.ts                 保存：localStorage 追加持久化
    stats.ts                   统计：四个看板指标
  data/seed.ts                 示例患者与初配/复查记录
  components/
    RegistrationForm.tsx       复查登记表单
    RecordList.tsx             历史记录与对比列表
    FilterPanel.tsx            患者/人群/镜片筛选
```

- 可继续扩展后端 API、权限、复杂图表
